# Architecture decisions

Accepted architectural choices are recorded here as numbered ADRs. Each record states its scope, context, decision, alternatives, consequences, evidence, and conditions for revisiting it. An accepted ADR represents the project owner's decision; experiments provide evidence but do not decide on their own.

- [ADR-0001: Use PySide6 and Qt Quick as the framework foundation](ADR-0001-pyside6-qt-quick.md) — accepted 2026-10-04 for the MVP rendering, windowing, and UI event foundation.
